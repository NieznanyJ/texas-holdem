# Product Scope

## Product

Web application for playing Texas Hold'em online.

## Main goals

Users can:

- create accounts
- log in
- create poker rooms
- join rooms
- play Texas Hold'em in real time
- reconnect after losing connection
- view current game state
- in game live chat

## Out of scope

For MVP:

- real money gambling
- tournaments
- mobile application
- advanced statistics
- matchmaking

## Main domains

- Authentication
- Lobby
- Rooms
- Game Engine
- Realtime Communication
- Player State
